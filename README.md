Sales Data Engineering Pipeline

Project Overview

This project demonstrates a sales data processing pipeline built using Databricks Free Edition, Python, PySpark, SQL, and Delta Lake.

The objective is to transform raw sales data into cleaned, structured, and business-ready datasets for analysis.

Architecture

- Bronze Layer: Stores raw sales data.
- Silver Layer: Cleans and transforms the data.
- Gold Layer: Stores aggregated datasets for reporting.

Technologies Used

- Databricks Free Edition
- Python
- PySpark
- SQL
- Delta Lake

Data Processing

- Removed duplicate records.
- Handled missing customer values.
- Standardized region names.
- Cleaned text fields.
- Created sales summaries by region and customer.
- Used SQL queries to analyze sales performance.

Dashboard

Create a sales dashboard to present key metrics and regional sales preformance.

key Learning Outcomes

- Understanding the Bronze, Silver, and Gold architecture.
- Working with PySpark DataFrames.
- storing and quering Delta tables.
- Performing SQL aggrregations.
- Transforming data for business reporting.
